# UI/UX 风格预览画廊

30 种精心制作的 Web 设计风格预览，每个风格页面包含完整的视觉演示和 Claude Code 使用命令。

## 在线预览

**[https://gws0920.github.io/ui-ux-preview/](https://gws0920.github.io/ui-ux-preview/)**

## 使用方式

在 Claude Code 中输入：

```
/ui-ux-pro-max 用 [风格名] 风格，生成 [页面描述]
```

示例：

```
/ui-ux-pro-max 用 Glassmorphism 风格，生成一个 SaaS 产品官网首页
/ui-ux-pro-max 用 Dark Cinematic 风格，做一个 AI 产品 Landing Page
/ui-ux-pro-max 用 Neo Brutalism 风格，生成一个创意工作室官网
```

## 技术栈

- 纯 HTML + Tailwind CSS（CDN）
- 无构建步骤，无依赖
- GitHub Pages 自动部署

## 部署

推送到 `main` 分支即自动部署至 GitHub Pages。
